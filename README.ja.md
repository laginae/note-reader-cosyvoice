# Cozy Read Aloud

[English](README.md) | [简体中文](README.zh-CN.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [한국어](README.ko.md) | 日本語 | [Español](README.es.md) | [Italiano](README.it.md) | [Português](README.pt.md)

Obsidian のノート、PDF、HTML ファイル、ウェブページを読み上げます。プライバシーを優先し、本文はローカルで抽出します。オンライン音声へのテキスト送信には明示的な同意が必要です。

## 特長

- 全文、選択範囲のみ、選択位置からの読み上げに対応。PDF でも使えます。
- 元の文書上で任意のハイライトを表示し、一般的な2段組 PDF 論文の読み順に対応します。
- 見出し、PDF のしおり、ローカルで推定したアウトラインから移動できます。
- 学術文書向けに、複雑な LaTeX 数式や数値の多い長い表を省略し、`sub`・`bar` の簡潔な読み方と連続する文献番号のまとめ読みを利用できます。
- 保存済みの Copilot の回答を読み上げます。Copilot のインストールと保管庫への会話保存が必要です。
- 音声の書き出し前に確認します。先行合成は既定で次の音声断片1つのみです。

## クイックスタート

1. Obsidian デスクトップ版でプラグインをインストールして有効にし、**Settings language** で日本語を選びます。
2. 音声エンジンを選択します。**System local speech** は API キーなしで対応するインストール済みシステム音声を使用します。**Xiaomi MiMo** と **OpenRouter** は API キーとオンライン処理への同意が必要です。キーの保存には Obsidian SecretStorage を推奨します。
3. **Edge TTS** にはサードパーティーの `edge-tts` を別途インストールします。この接続先には明示的な ZDR 保証がありません。OpenRouter は ZDR ルーティングを強制しますが、テキスト自体はサービスに送信します。
4. 文書を開き、音声アイコンでツールバーを表示します。再生、一時停止、速度、読み上げ範囲を操作できます。

## 学術文書の読み上げ

同名の設定欄で数式と表を管理できます。自動モードでは複雑な数式と長い数値表を省略し、小さな表や文章中心の用語集は残します。省略の通知はオフにできます。元のファイルは変更しません。PDF の表は慎重に判定するため、構造情報のない数式や表をすべて認識できるわけではありません。

PDF には選択可能なテキストが必要です。スキャン文書は先に OCR を行ってください。ローカル HTML には HTML Reader などの対応ビューアーが必要です。表示言語と音声は独立しており、数式の変換は現在中国語と英語に対応しています。一部の詳細な説明や補助ダイアログは英語です。

機密性の高い文書にはローカルのシステム音声や CosyVoice を使用してください。[英語の完全ガイド](README.md) · [不具合の報告](https://github.com/laginae/note-reader-cosyvoice/issues)。キーや非公開文書を添付しないでください。
