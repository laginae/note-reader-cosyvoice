# Cozy Read Aloud 1.7.9

- In the mini outline and the Outline & Read sidebar, choose **Read from this section** or **Read this section only** on another heading while playback is active or paused. The new chapter replaces the current reading without a separate Stop action.
- A single click still only navigates. If double-click reading is enabled in the mini outline, it can also switch chapters. Section reading remains unavailable during audio export.
