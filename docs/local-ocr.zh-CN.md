# 本机 OCR：扫描 PDF 和图片朗读

这是默认关闭的**桌面端可选功能**，支持扫描 PDF、PNG、JPEG、WebP 中的中英文印刷文字，不是图片描述、图表解读或数学公式识别模型。

## 使用方法

1. 从 [1.4.0 发布附件](https://github.com/laginae/note-reader-cosyvoice/releases/tag/1.4.0)下载 `cozy-ocr-helper-windows-x64.zip`，保留解压后的完整目录。当前仅提供并验证 Windows x64 助手包；源码具备跨平台构建基础，但 macOS/Linux 对应安装包及插件集成尚未完成验证，暂不列为已支持平台。助手不属于 Obsidian 自动更新的三个插件文件，不会自动下载安装。
2. 在 **学术阅读 → 本机 OCR** 中填写 `CozyOcr.exe` 的完整路径，打开“扫描 PDF 与图片朗读”。也可把完整助手目录放到插件目录下的 `ocr-helper/`，此时路径留空。
3. 打开 PDF 或图片，运行命令 **Recognize PDF or image text (local OCR)**，或使用文件右键菜单“识别文字并朗读（OCR）”。打开图片后执行“朗读当前文件”也会进入识别窗口。
4. 选择起止页后点“识别”。默认仅第一页，每次最多 10 页；已有文字的 PDF 页面优先直接提取。若扫描件只有可选页眉或原文字层损坏，可取消“已有文字的页面直接提取”。横置、倒置扫描件可手动设置整页旋转角度。
5. 校对、修改预览文字，再点“朗读本页”“朗读选中文字”或“朗读全部结果”。使用原有音色、在线处理授权和播放控制。

## macOS / Linux：未验证的自行构建

助手使用 .NET 和跨平台的 SimdPaddleOCR，源码层面具备可移植基础，因此 **macOS/Linux 理论上可行，但本项目尚未完成这两个平台的构建、Obsidian 集成及实际识别验证**。当前 Windows x64 安装包不能直接在 macOS/Linux 上运行，也不应把上游支持理解为本插件已经通过测试。

有开发经验的用户可以使用 .NET 10 SDK，从 `ocr-helper/CozyOcr.csproj` 按实际系统和处理器自行构建，例如 Apple Silicon 使用 `osx-arm64`、Intel Mac 使用 `osx-x64`，Linux 使用 `linux-x64` 或 `linux-arm64`，并保留完整发布目录。请先用公开、非敏感的单页样例验证启动、识别、取消和插件调用；这些目标仅为构建方向，不代表已验证兼容性或性能。

遇到问题可在 [GitHub Issues](https://github.com/laginae/note-reader-cosyvoice/issues) 反馈。建议提供系统及版本、处理器架构、Obsidian/插件版本、构建命令、报错信息和可公开的最小复现样例。提交前删除用户名、私人路径、正文、密钥和完整凭据；不要上传私人 PDF 或原始配置文件。自行验证成功也欢迎反馈，但单次成功不等于所有设备均受支持。

## 启动速度与性能

- 默认 Small 模型偏重中英文正文质量；Tiny 更快，但密集英文、小字可能漏字。
- 普通插件启动不启动 OCR 进程、不加载模型、不下载模型。真正需要识别时才启动本机助手。
- 逐页串行识别，CPU 最多使用四个识别工作线程。识别完成、取消、关闭窗口或卸载插件时退出助手，释放模型，不保留常驻大缓存。
- PDF 最大 100 MB；图片最大 20 MB、解码前最大 2500 万像素。识别栅格最多 400 万像素、最长边 2400 像素；结果最多 20 万字符。
- 单页助手超时两分钟，整次任务超时五分钟；支持取消。已完成页仍可校对。

此前本机公开合成样例测试中，Tiny 进程峰值内存约 434 MB，Small 约 601 MB。实际内存随内容与运行环境变化，不能当作移动端数据或性能保证。**识别时仍会使用较多内存**，按需加载只是避免普通启动承担这部分开销。

## 隐私与识别边界

OCR 本身只在本机处理，不上传图片、不使用云端 OCR、不读取语音密钥。像素经本机进程管道传递，不写临时图片。请只使用可信助手，配置其路径意味着允许执行该本地程序。

原 PDF/图片不变，不插入隐藏文字层；识别结果不写设置、日志或磁盘 OCR 缓存。结果在识别窗口关闭或清除后释放。但如果选择在线语音，**被朗读的识别文字仍会按原有授权发送给相应语音服务**；语音音频缓存继续遵循原有设置。

低置信度行数只是校对提醒，不是准确率保证。识别结果尽可能使用现有双栏排序和公式过滤，但没有原始字体、LaTeX 结构，公式、手写字、表格、页眉页脚和脚注分离仍可能出错。正文中的变量也可能被误识别，请先校对。测试中逐行自动翻转会损坏正常公式，因此助手不自动翻转单行；可手动旋转整页。

本次范围是**识别结果预览与朗读**，暂不包括扫描原图高亮、大纲、可搜索 PDF 输出、OCR 音频导出或 OCR 续读位置保存。已有文字的 PDF 常规朗读不受影响。移动版与网页版另外采用按需加载的浏览器 OCR 资源包，不使用这个桌面助手。

源码构建、依赖版本及分发说明见[英文技术说明](local-ocr.md#build-the-optional-helper)。最终用户使用完整独立助手包，不需要安装 Python 或 .NET SDK。
