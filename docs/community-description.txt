Privacy-first read aloud with fast playback startup for notes, text PDFs, HTML and Obsidian Web viewer pages. Read all text, a selection, or continue from a selected position.

Follow along with adjustable highlighting and an in-place toolbar. Navigate headings or PDF bookmarks; infer PDF/HTML outlines locally. Progressive parsing helps playback start sooner; timing depends on document size and speech service.

Try Xiaomi MiMo for Chinese, Edge TTS for online voices, installed system voices for offline use, or OpenRouter for model choice and enforced ZDR. MiMo is temporarily free; costs and quotas vary. Edge needs a helper. Local CosyVoice and Azure are also available.

Online speech requires consent and sends text to providers. Only one upcoming audio part is prefetched by default. Confirm scope and destination before audio export.

Scans need OCR; complex layouts can affect outlines and highlighting. Desktop only. See the README for setup and privacy details.
