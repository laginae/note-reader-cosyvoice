# Cozy Read Aloud 1.8.0

- New installations start with Everyday reading. Simple tables introduce columns once, numeric comparisons keep labels, and simple functions follow the language of the passage. Complex formulas and long numeric tables still use smart skipping.
- Reading content offers Academic detail and Custom. Upgrades retain existing choices, and switching presets never replaces the saved custom settings. An ambiguous empty settings read will not initialize over an existing file.
- Local OCR settings link to the matching Windows x64 helper and installation guide. Other desktop targets show unverified source-build instructions instead of a Windows executable. Downloads remain manual and OCR remains off by default.
