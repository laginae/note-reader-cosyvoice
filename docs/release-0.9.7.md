# 0.9.7 - ElevenLabs options and everyday pronunciation examples

- Add four ElevenLabs models and six voice presets through OpenRouter without changing existing defaults.
- Offer optional, default-off continuity controls only for supported models, with mandatory ZDR and bounded context from the selected reading range.
- Add local term pronunciation rules for every engine and audio export. Examples use familiar abbreviations: `AI = artificial intelligence` in English and `AI = 人工智能` in Chinese.
- Preserve original document text and reading positions while keeping expanded requests within engine limits.
- Include the recent interval-formula improvements and normal-speed ElevenLabs synthesis with player speed controls.

No paid listening tests or new iOS/iPadOS device tests were performed. Continuity remains experimental; improved prosody is not guaranteed. No cloud dictionary is uploaded. Online engines receive substituted speech text, not the rule list.

## 使用提示

选择受支持的 ElevenLabs 模型后，可在高级选项中开启分段衔接实验功能。通用的本地术语读法位于“学术阅读”，例如 `AI = 人工智能`，将缩写展开为完整读法，不修改笔记原文。
