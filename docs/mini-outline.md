# Mini Outline / 迷你目录

Available for Markdown, text PDFs and local HTML displayed in HTML Reader. External Web viewer pages are not included. It works without starting speech and does not edit notes or PDF bookmarks.

## Controls

- **Pause/resume** beside Pin controls the existing reading session, independently of the main toolbar or selected heading. **More outline options > Playback button visibility** defaults to **Follow header**: on desktop it hides with the header when idle, including while playing or paused. Choose **Visible during reading** to keep this button visible during an active/paused session. Touch/mobile keeps it visible in either mode. Hiding preserves its space and keyboard access; it does not pause playback or change the separate floating button. The button is disabled when no reading can be paused, including exports. Its accessible hint includes the source label; it never starts speech or jumps to a chapter.
- **Floating playback controls** under **Reading shortcuts** is off by default. Enable it to show one lower-right control in the active supported Markdown/PDF/local HTML pane, even with the main toolbar and outline closed. It is shown only during an active/paused session and removed after stop/completion or disabling. It shares the same playback state, preserves touch targets and avoids known bottom bars, the visual viewport and safe-area insets. If an open outline occupies the same corner in a very short viewport, the floating control yields to the outline's pause button until the overlap clears. Other third-party overlays may still need testing. No extra audio requests or polling loop are added; placement observers exist only while the floating button is mounted.

- Open from the edge button, reading toolbar's outline icon, or the Toggle mini outline command. Click again, use Close or press Escape to close; outside clicks close an unpinned directory.
- **Open mini outline on startup** is off by default. Enable it once to automatically open and pin the current document outline after the workspace restores, without opening the reading toolbar or starting speech. The edge entry is hidden while expanded. Manual dismissal prevents another automatic opening during that plugin session; the entry can then appear according to **Mini outline button**, with toolbar/command access retained. If no supported document is active at startup, opening waits until one becomes active. Other plugins are never changed.
- **Collapsed appearance** in **More outline options** offers **Auto / Chapter lines / Outline icon**. Auto uses chapter lines for mouse input and a single icon with a minimum 44-pixel target for touch. Lines are ordered by chapter, with shorter marks for deeper headings, not proportional page positions. At most 24 marks are shown, fewer in short panes; dense outlines summarize shallower sections while the expanded list retains every heading. A darker line marks browsing; an accent-colored line of unchanged thickness marks a reliably mapped reading section, taking priority when both coincide. There is no extra dot, flashing or width change; pausing retains the reading mark. Until an outline has loaded, the entry remains an icon; no extra PDF analysis is started to populate the rail.
- Hovering chapter lines for 200 ms opens the existing outline without speech, navigation or focus stealing. With mouse input, unpinning leaves it open until the pointer exits, then collapses after 250 ms; re-entry cancels that delay. Search, options, a section menu or keyboard interaction holds it open. Touch unpinning collapses immediately, and reopening uses tap. Keyboard users open the entry with Enter/Space and return with Escape. Explicit **Hide button** and Auto coexistence with Floating TOC still override the collapsed entry. Icon hover remains separately opt-in.
- The desktop mouse icon bar contains Pin, Pause/resume, Search, Return to reading (a return arrow), Go to document top/bottom and Options; Close is inside Options. When idle, icons fade out over 150 ms, leaving a subdued pin if the directory is pinned; pause/resume remains visible only when explicitly configured above. Hover anywhere inside the directory to reveal all controls. Keyboard focus, an open search field/options group or a section menu keeps them visible. Mouse-click focus alone does not keep the bar visible after leaving. The bar keeps its height so headings do not move. Reduced-motion preferences disable the fade; older engines without the required selectors retain visible controls.
- Touch/mobile and narrow layouts keep their top icons visible, including Close. Document top/bottom buttons share the header when all controls fit in one row; otherwise both move into Options together. This uses available space and rendered button sizes rather than a fixed directory-width threshold. Touch devices do not require hover or smaller hit targets. Search opens on demand and includes matching headings and their parents; hiding it clears the filter. Options also reveals expanded levels (one, two, three or all) and Refresh. Pin keeps the directory open while navigating.
- On mouse-first computers that also support touch, touch capability alone does not keep the header visible. Actual touch or pen interaction keeps controls available; returning to mouse input restores idle hiding. This changes only the in-memory display state, without reloading headings, saving preferences or starting speech.
- **Go to document top/bottom** navigates to the actual beginning/end of Markdown, PDF or local HTML, not the first/last heading or the directory's scroll position. It neither starts speech nor changes the selected text. A pinned directory stays open; an unpinned one closes after navigation. On desktop, enabled document auto-follow is paused to prevent pulling the viewport back to the reading position; playback itself continues unchanged. Changed or closed targets cancel pending navigation.
- Titles use interface fonts. **Heading display lines** offers one, two, three or four lines before truncation; two is the default. The full title remains available in the accessible label/hover hint and through **Show full heading** in the heading context menu or top **Outline options**, including on touch devices. Changing the line limit preserves manually expanded titles. The list scrolls independently. Common Markdown presentation markers are removed from the directory label only (for example, `$x$` displays as `x`); source text, offsets, reading ranges and PDF/HTML titles are unchanged. This is not a full formula renderer.
- A title navigates only. Heading rows have no trailing menu button or reserved menu space, including the reading row. Right-click a heading or focus it and press Shift+F10/the context-menu key for **Read from this section**, **Read this section only** (including descendants) and the full-title control. Top **Outline options** also provides these actions for touch and keyboard access, with a caption identifying the selected section or, when none is selected, the reliably located browsing/reading section. Unknown targets disable the actions instead of guessing a heading. Switching documents or closing the directory cancels pending actions. These explicit reading actions use the configured engine and its existing consent requirements; online speech may incur charges.
- Section captions and actions share a compact row, without a reserved two-line caption height. Long captions truncate visually while retaining their accessible label. When space is tight, or on touch/mobile layouts, **Section actions** opens the same three commands in a menu instead of squeezing or wrapping three icon buttons. Resizing preserves the selected target and keyboard focus; opening these controls does not start speech.
- **Double-click heading to read** is off by default in Mini outline settings. With it enabled, a desktop mouse single-click navigates immediately and keeps the directory open; double-click starts reading from that heading through the remaining document, not just that section. Click outside to dismiss an unpinned outline. Touch, pen and keyboard navigation do not opt into this gesture; use the section actions in top **Outline options** instead. It uses the same playback and consent path as **Read from this section**. Closing, switching documents or choosing another heading cancels a pending double-click start.
- Accent text marks the browsing section; a small play marker additionally identifies the reading section when mapping is reliable. Directory scrolling pauses its automatic tracking; Return to reading resumes tracking and locates the current reading. On desktop, deliberate chapter navigation also pauses enabled document auto-follow.
- Playback settings place **Reading shortcuts** before **Mini outline**. The main outline controls are **Open mini outline on startup**, **Mini outline button**, **Outline width** and **Heading display lines**. The button preference remains editable with startup opening enabled, so it can control the entry after manual collapse. **More outline options** starts collapsed and contains collapsed appearance, playback-button visibility, left/right placement, initial expanded depth, transparent background, double-click reading and icon hover opening. Collapsing it does not reset any saved choice. **Mini outline button** offers Auto / Always show / Hide button and controls both collapsed entry styles. Changing these preferences does not restart synthesis.
- **Outline width** provides a 180-600 pixel slider with a numeric value and a reset icon. Changes update the existing directory immediately without reloading headings or starting playback. Reset retains the responsive defaults: 300 pixels on desktop and 340 on touch screens or narrow windows. The actual width is limited by the document pane; a saved wider value is retained when the pane becomes narrow. Header navigation adapts to measured space, including theme button sizes. Touch controls wrap instead of shrinking their hit targets; the two document-edge actions stay together.
- Desktop mouse layouts hide the scrollbar thumb while idle and reveal it on directory hover or keyboard focus. Color-only hiding preserves scrolling and layout, so headings do not rewrap when the pointer enters. Touch/pen interaction keeps native scrolling feedback available. High-contrast mode and older environments retain their normal scrollbars.
- Transparent background is opt-in for desktop mouse layouts, best used with wide document margins. Text and icons remain opaque; hovering or focusing the directory restores a nearly solid backing. Phones, tablets and narrow windows retain a solid background and larger touch controls. Escape, the outline toggle and the appropriate Close action remain available. When the Editing Toolbar reading icon is off, its action setting is hidden without discarding the saved choice.

- **Show stop reading button** is on by default inside **Floating playback controls > More floating control options**. This group starts collapsed and is hidden when the main switch is off. Folding changes only the settings display, not the saved stop-button choice or playback. Re-enabling the main switch preserves that choice and starts with the options collapsed. A square Stop button opens above Pause/resume on desktop hover or keyboard focus, without moving Pause. Both buttons and their gap share one pointer area, with a 250 ms delay before hiding after leaving. Mouse-click focus alone does not keep Stop visible. Touch keeps both controls visible with at least 44-pixel targets. Stop uses the existing player action and remains available while pause/resume or synthesis is pending; duplicate or stale-session clicks are ignored. If there is insufficient room above Pause, only Stop is hidden; the main player retains its Stop action. Disabling this preference preserves the main pause button and does not interrupt speech.

## Coexistence and Performance

An open, pinned outline follows the active document when switching files or tabs. Only the newly active supported document is loaded; focus and playback are unchanged. Closing or unpinning the current outline stops this behavior. A failed load remains open for manual retry, and late results cannot replace a newer document's headings. No background document scan is added.

After manual collapse/unpin, the entry remains available across note/tab switches and when returning, without reopening the panel. Visible chapter lines refresh only the active Markdown/local HTML outline; PDFs reuse an already valid outline cache or retain an icon until opened. Hidden entries and touch Auto/icon-only entries do not preload headings. Explicit hiding and Floating TOC coexistence always win. This in-memory intent resets when the plugin restarts; startup opening retains its existing opt-in behavior.

**Show 5-second seek buttons** is off by default under **Floating playback controls > More floating control options**. It places Back/Forward beside Pause with the same hover/focus reveal and touch visibility as Stop. Space is reserved before reveal so Pause does not move under the pointer. Insufficient space hides the pair; unsupported seeking disables it. These actions reuse the existing player and preserve pause state. Mobile supports seeking within the current loaded online audio, not device system speech or cross-segment navigation.

Auto checks enabled IDs for Floating TOC and several known floating-outline plugins. It hides only Cozy's edge button; command/toolbar access remains. Use Hide button to retain another plugin's directory, or Always show to use both intentionally. Other plugin settings and files are never modified. Placement accounts for visible document, reading, PDF and Editing Toolbar bars in the current pane, including toolbar insertion, resizing and visibility changes. This is targeted avoidance, not a guarantee for every third-party overlay or theme.

No whole-vault scan, OCR loading or additional speech requests are introduced by the directory. With automatic opening off (the default), startup does not read document text or parse PDFs. When opted in, opening is deferred until workspace restoration and loads only the active supported document, never background tabs or a saved reading source. A currently active PDF may require its first analysis; existing caches are reused. Automatic opening does not navigate or steal keyboard focus, and a failed load waits for manual retry. A visible collapsed rail reuses cached headings and coalesces position updates over 180 ms, without a polling loop, rebuilding rows or loading documents. Hidden/icon-only entries do not track positions. The initial expanded list renders up to 200 visible headings; Show more and following a later chapter extend it. Search, folding, pin and scroll state are memory-only, bounded to 40 document entries and cleared on plugin reload. Only preferences are saved, not a document path or its headings.

PDF headings and exact positions depend on bookmarks, text layout and the viewer; some targets resolve only to a page. Uncertain reading positions are not guessed. Changing a file or view invalidates old targets. A first PDF analysis may be slow for a large file; scanned documents still require the separate optional OCR workflow.

## 中文说明

目录已固定且展开时，切换笔记或标签页会保持目录展开，并更新为当前文档的标题。只读取新激活的受支持文档，不抢焦点、不改变播放。关闭或取消固定当前目录后，不再随文档切换自动展开。加载失败时保留重试提示，旧文档的延迟结果不会覆盖新目录，不增加后台文档扫描。

手动收起或取消固定后，侧边入口在切换笔记、标签页以及返回原笔记时仍可用，不自动展开。可见短线仅更新当前 Markdown／本地 HTML 目录；PDF 有有效缓存时复用，否则保留图标，待打开后分析。隐藏入口、触屏自动样式和纯图标样式不预读标题。隐藏入口及 Floating TOC 共存规则始终优先；此收起状态只保存在本次运行内，重启仍遵循原有的可选启动设置。

“**悬浮播放控制 → 更多悬浮按钮选项 → 显示前后 5 秒按钮**”默认关闭。开启后，在暂停按钮左右提供后退／前进，按停止按钮相同的悬停／键盘及触屏规则显示。提前预留空间，避免悬停时移动暂停按钮；空间不足时隐藏这对按钮，不支持定位时禁用。沿用现有播放器并保留暂停状态。移动端仅定位当前已加载的在线音频，不支持设备系统语音或跨段定位。

在“**悬浮播放控制 → 更多悬浮按钮选项**”中可设置“**显示停止朗读按钮**”（默认开启）。选项默认折叠，折叠不关闭停止功能。关闭主开关时隐藏整个组选项，重新开启时保留原选择并保持折叠。桌面端悬停或键盘聚焦时，在暂停／继续按钮上方显示方形停止图标，原按钮位置不变。两按钮及中间空隙属于同一操作区，移出后延迟 250 毫秒收起；鼠标点击留下的焦点不会让按钮持续展开。触屏端两个按钮常显，点击区域至少 44 像素。停止沿用现有播放器流程，暂停／继续操作或合成等待期间仍可使用；过滤重复点击及旧会话点击。上方空间不足时仅隐藏停止按钮，主播放器仍保留停止操作。关闭此设置不影响暂停按钮，也不打断朗读。

迷你目录支持 Markdown、文本型 PDF 和 HTML Reader 中的本地 HTML，不包括外部 Web viewer 网页。不需要开始朗读即可使用，也不改写笔记或 PDF 书签。

“**启动时打开迷你目录**”默认关闭。开启一次后，每次工作区恢复完成都会为当前文档自动打开并固定目录，不需要先打开朗读工具栏，也不会启动朗读；展开时隐藏侧边入口。手动收起后，本次插件运行期间不会再次自动弹出，此时是否显示入口仍由“迷你目录按钮”决定，也可用工具栏或命令打开。启动时没有支持的活动文档，则等到打开一个支持的文档后执行一次。不改动 Floating TOC 等其他插件。

“**更多目录选项 → 收起样式**”提供“**自动／章节短线／目录图标**”。自动模式下，鼠标使用章节短线，触屏使用至少 44 像素的单个图标入口。短线按章节顺序排列，较深层级较短，不代表页码或进度百分比。最多显示 24 条，矮窗口进一步减少；标题密集时概览较浅层章节，展开后仍能访问全部标题。浏览章节用较深短线标记，能可靠匹配的朗读章节仅用强调色标记，粗细保持不变；两者重合时优先显示朗读状态。不增加小圆点，不闪烁、不改变长度，暂停时保留位置。首次尚无目录数据或文档已经变更时先显示图标，不为绘制短线额外分析 PDF。

鼠标在短线上停留 200 毫秒后展开现有目录，不朗读、不跳转，也不抢键盘焦点。取消固定后，鼠标仍在目录内时保持展开，移出后延迟 250 毫秒收起；移回可取消收起。搜索框、选项、章节菜单和键盘操作会保持目录打开。触屏取消固定后立即收起，再点击入口展开；键盘可用 Enter／空格打开、Escape 收起并回到入口。“隐藏按钮”以及自动模式下与 Floating TOC 共存的规则优先，不会因取消固定重新显示被隐藏的入口。图标样式的悬停展开仍单独设置。

桌面鼠标布局的顶部包含固定、暂停／继续、搜索、回到朗读位置、到文档顶部、到文档底部和目录选项；关闭按钮收进“目录选项”。鼠标移出且未在操作时，顶栏图标在 150 毫秒内淡出，已固定时保留低调的固定图标；暂停／继续按钮默认也隐藏，选择“朗读时常显”后才在有朗读会话时保留。鼠标移入整个目录即可显示全部图标；键盘焦点、已展开的搜索框或目录选项、章节菜单都会让图标保持可见。仅由鼠标点击留下的焦点不会阻止隐藏。顶栏保留原高度，标题不会上下跳动；系统要求减少动态效果时取消淡入淡出，旧环境不支持必要选择器时保留常显。

“**暂停／继续**”只控制已有朗读，不受目录当前选中章节影响，不需要打开顶部播放栏；没有可暂停的朗读或正在导出时禁用。按钮提示包含当前朗读来源，不会重新起读或跳转章节。在“**更多目录选项 → 播放按钮显示方式**”中，默认“**随顶栏自动隐藏**”，播放和暂停时均按顶栏规则显示；也可选择“**朗读时常显**”。触屏两种模式都保持可见。隐藏时保留占位和键盘访问，不暂停播放，也不影响独立悬浮按钮。

“**朗读快捷入口**”提供“**悬浮播放控制**”，默认关闭。开启后，在当前支持的 Markdown／PDF／本地 HTML 文档右下角显示一个独立按钮，即使目录和顶部播放栏均关闭也可使用。仅有朗读或暂停会话时显示，停止、结束或关闭设置后移除；分屏时只显示一个。沿用现有播放状态，避让已知底部栏、可视窗口边界和安全区域，触屏点击区域保持至少 44 像素。很矮的窗口中，如果目录占据同一角落，悬浮按钮暂时隐藏，由目录里的暂停按钮继续提供控制；目录收起或不再重叠后恢复。第三方覆盖层仍需实际测试；不增加音频请求或轮询，布局监听只在悬浮按钮显示期间存在。

手机、平板、触屏和窄窗口的顶部图标保持常显，包括关闭按钮；顶栏能同排容纳全部按钮时显示“到文档顶部／底部”，放不下时两个按钮一起移入“目录选项”。按实际可用空间和按钮尺寸判断，不再使用固定目录宽度门槛，也不缩小触屏点击区域。触屏取消固定会立即收起目录；鼠标操作则在移出后收起。也可按 Escape、使用目录开关，或在未固定时点击目录外部收起。返回按钮使用简单回转箭头。搜索框按需展开，收起时清除筛选；“目录选项”还提供层级选择和刷新。

同时支持鼠标和触屏的电脑，不会仅因系统报告触屏能力而一直显示顶栏。鼠标操作时仍会自动隐藏；实际使用手指或触控笔后保持显示，回到鼠标操作则恢复隐藏规则。此切换只影响内存中的显示状态，不重新读取目录、不保存设置，也不启动朗读。

“**到文档顶部／底部**”定位到 Markdown、PDF 或本地 HTML 正文的真正开头／结尾，不是首末标题或目录列表的首尾；不开始朗读，也不改变原有选区。已固定的目录保持打开，未固定时跳转后收起。桌面端会暂停已开启的正文自动跟随，以免马上被拉回朗读位置，但不暂停语音播放。文档变化或关闭目录会取消尚未完成的跳转。

标题使用界面字体，“标题显示行数”可选一、二、三或四行，默认两行，超出后省略。悬停提示和无障碍标签保留完整标题；标题右键菜单和顶部“目录选项”中都提供“展开完整标题”，触屏也可使用后者。更改行数不会收起已手动展开的标题。目录标签清理常见 Markdown 格式标记，例如 `$x$` 显示为 `x`；不改原文、定位偏移、朗读范围或 PDF/HTML 标题，也不加载完整公式渲染器。

点击标题只跳转；标题行不显示或预留行末菜单按钮，当前朗读行也一样。右键标题，或聚焦标题后按 Shift+F10／菜单键，可选择“从本节朗读”“只朗读本节”和完整标题选项。顶部“目录选项”中也提供相同操作，方便触屏和键盘使用，并标明目标章节：优先使用已选择的章节，否则使用可靠定位的浏览／朗读章节；无法确定时禁用操作，不猜测首个标题。切换文档或关闭目录会取消尚未执行的操作。朗读仍遵循原有引擎授权，在线接口可能计费。搜索会保留匹配标题的父级，支持层级折叠和固定显示。浏览位置用文字强调色表示，可靠识别的朗读章节另加小播放标记。手动浏览目录后不会强行抢回滚动位置，可用“回到朗读位置”恢复。桌面端主动跳转章节也会暂停已开启的正文自动跟随。

章节名和操作共用紧凑的一行，不再固定预留两行标题高度。长章节名显示省略号，无障碍标签仍保留全文。空间不足或使用触屏／移动布局时，通过“章节操作”菜单打开相同的三个命令，不挤压或换行堆叠图标。调整宽度不会改变目标章节，并保留必要的键盘焦点；打开选项或菜单本身不启动朗读。

“迷你目录”设置中可开启“**双击标题开始朗读**”，默认关闭。开启后，鼠标单击标题立即定位并保留目录，双击从该标题继续朗读到文档结尾，而非只读本节；未固定时点击目录外即可收起。触屏、触控笔及键盘不启用双击朗读，请使用顶部“目录选项”中的章节操作。此操作沿用“从本节朗读”的播放和授权流程；关闭目录、切换文档或选择其他标题会取消尚未开始的双击播放。

播放设置中，“朗读快捷入口”位于“迷你目录”上方。迷你目录主区保留“启动时打开迷你目录、迷你目录按钮、目录宽度、标题显示行数”；自动打开开启时也能设置手动收起后的入口。默认折叠的“更多目录选项”包含收起样式、播放按钮显示方式、目录位置、默认展开层级、透明背景、双击标题开始朗读和鼠标悬停展开目录图标，收起分组不清除原选择。“迷你目录按钮”提供自动、始终显示、隐藏按钮三个选项；同时控制短线和图标两种侧边入口。自动模式下，启用 Floating TOC 等浮动目录插件时隐藏此入口；仍可通过朗读工具栏或命令打开迷你目录，不影响其他插件。侧边入口会避让当前窗格的文档标题栏、朗读栏、PDF 工具栏和 Editing Toolbar，并响应其出现、尺寸及显隐变化；不承诺识别所有第三方覆盖层。

透明背景默认关闭，可在桌面端留白较宽时开启；操作目录时增强底色，文字和图标不透明。手机、平板和窄窗口仍使用实色背景及较大的点击区域。“鼠标悬停展开目录图标”放在“更多目录选项”中，默认关闭；章节短线始终支持鼠标悬停展开。关闭 Editing Toolbar 朗读图标会隐藏其默认动作设置，但保留原选择。

“**目录宽度**”提供 180–600 像素滑块、数值显示及恢复默认图标。调整立即应用到现有目录，不重新读取标题或启动朗读。恢复默认后，桌面使用 300 像素，触屏或窄窗口使用 340 像素；实际宽度始终受当前文档窗格限制。分屏或缩窄窗口不会覆盖已保存的宽度。导航按钮按实测空间适配，兼顾主题的按钮尺寸；触屏按钮可以换行，但不缩小点击区域，顶部／底部两个动作始终放在一起。

桌面鼠标布局中，空闲时隐藏滚动条滑块，鼠标移入目录或通过键盘聚焦后显示。只改变颜色，不改变滚动区域或占用宽度，标题不会因显隐重新换行，滚轮仍可正常使用。触屏和触控笔保留原生滚动反馈；高对比度模式及较旧环境不强制隐藏滚动条。

收起后只有可见的章节短线复用缓存跟踪位置，将更新合并到 180 毫秒内，不轮询、不重新渲染标题或读取文档；隐藏入口和纯图标入口不跟踪位置。不扫描全库或加载 OCR。自动打开默认关闭，此时启动不读取文档或解析 PDF；开启后仅在工作区恢复完成时读取当前活动文档的目录，不解析后台标签页或此前朗读的其他文档。当前为 PDF 时，首次目录分析仍可能需要等待，后续复用已有缓存。自动打开不跳转正文、不抢键盘焦点，失败后等待手动重试。工具栏布局监听不读取正文。搜索、折叠、固定和滚动状态只放在内存；只持久保存偏好设置，不保存文档路径或标题，也不向语音服务发送内容。

Desktop and mobile use the same directory UI. Browser layout checks are not iPhone/iPad/Android physical-device acceptance; mobile background playback and OCR remain experimental and off by default.
