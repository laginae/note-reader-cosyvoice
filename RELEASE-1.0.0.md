# 1.0.0

The desktop reader reaches version 1.0.0 with the reading features and configuration controls from 0.9.10.

- Simplify the English and Chinese README introductions and demo captions.
- Move context-menu and floating-toolbar instructions into the usage section.
- Clarify that Editing Toolbar is an optional, separately installed plugin, not a requirement for ordinary reading.
- Document the independent switches, the two floating-icon actions, and the supported Markdown editor modes.

This release updates documentation and version metadata; it does not change speech synthesis, playback or highlighting behavior. Existing settings are preserved. The mobile edition remains a separate release.
