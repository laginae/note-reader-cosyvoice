# Cozy Read Aloud

[English](README.md) | [简体中文](README.zh-CN.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | Русский | [한국어](README.ko.md) | [日本語](README.ja.md) | [Español](README.es.md) | [Italiano](README.it.md) | [Português](README.pt.md)

Озвучивание заметок, PDF, HTML-файлов и веб-страниц в Obsidian. Конфиденциальность на первом месте: текст извлекается локально, а онлайн-синтез требует явного согласия на передачу текста.

## Возможности

- Читать весь документ, выделенный текст или продолжать с выделенного места, в том числе в PDF.
- Подсветка в исходном документе и поддержка распространённых двухколоночных научных PDF.
- Переход по заголовкам, закладкам PDF или локально определённому оглавлению.
- Научное чтение: пропуск сложных формул LaTeX и длинных числовых таблиц, краткие обозначения `sub` и `bar`, объединение соседних ссылок на литературу.
- Чтение сохранённых ответов Copilot: установите Copilot и сохраняйте диалоги в хранилище.
- Экспорт аудио с подтверждением. По умолчанию заранее синтезируется только один следующий аудиофрагмент.

## Быстрый старт

1. Установите и включите плагин в настольном Obsidian. В **Settings language** выберите Русский.
2. Выберите движок. **System local speech** использует совместимые установленные системные голоса без API-ключа. Для **Xiaomi MiMo** и **OpenRouter** нужны ключ и разрешение онлайн-обработки. Для ключей предпочтительно Obsidian SecretStorage.
3. Для **Edge TTS** отдельно установите стороннюю программу `edge-tts`; её интерфейс не гарантирует ZDR. Запросы OpenRouter принудительно используют маршрутизацию ZDR, но текст всё равно передаётся сервису.
4. Откройте документ и нажмите значок аудио, чтобы показать панель чтения с паузой, скоростью и выбором области.

## Чтение научных текстов

В одноимённом разделе настройте формулы и таблицы. Умный режим пропускает сложные формулы и длинные числовые таблицы, сохраняя небольшие таблицы и текстовые глоссарии. Краткое объявление пропуска можно отключить. Исходные файлы не изменяются. Фильтрация PDF консервативна и не распознаёт все неструктурированные формулы.

В PDF должен быть выделяемый текст; для сканов нужен OCR. Для локальных HTML установите совместимый просмотрщик, например HTML Reader. Язык интерфейса не меняет голос; преобразование формул пока поддерживает китайский и английский. Некоторые подробные справки и дополнительные диалоги остаются на английском.

Для чувствительных данных используйте локальные системные голоса или локальный CosyVoice. [Полная инструкция на английском](README.md) · [Сообщить об ошибке](https://github.com/laginae/note-reader-cosyvoice/issues), не прикладывая ключи и личные документы.
